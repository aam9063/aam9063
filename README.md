## 🧭 How I work

```
spec  →  tasks  →  isolated agents  →  review gate  →  reviewable commits
```

- **Specs before code.** Written requirements, quoted verbatim, before a single line of implementation.
- **Agents get bounded scope.** One task, one surface, an explicit definition of done.
- **Every change is reviewed.** Agent output is a proposal, never the final word — and reviewer output is checked too.
- **Small, auditable slices.** Commits you can read in one sitting, tests and docs next to the behavior they describe.
